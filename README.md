# Strona parafii Matki Bożej z Góry Karmel w Dąbkach

Strona: https://parafia-dabki.pl

- `index.html`, `img/` – gotowa strona publikowana przez GitHub Pages.
- `zrodla/` – pliki źródłowe. Po zmianie uruchom `python3 zrodla/build.py`, który odtworzy `index.html`.
- Ogłoszenia i godziny mszy są pobierane z Arkusza Google (ustawienie `arkuszId` w `zrodla/parafia.js`). Dopóki jest puste, strona pokazuje dane wpisane w kodzie.
